# یافته‌های بررسی سان اپ

مبنای بررسی: ۲۰۲۶/۱۰/۰۱، کد مونوریپو، صفحات محلی و مسیرهای منتخب تولید با نقش Manager. «مشاهده» یعنی نتیجه UI یا API در همان بررسی؛ «کد» یعنی تأیید از منبع و نه اجرای کامل گردش. موارد این جدول موجودی کامل همه باگ‌ها نیستند. هیچ آزمون نوشتن عملیاتی در تولید انجام نشده و نقش واقعی Client و Expert تولید بررسی نشده است.
