# Saan Monorepo

این مونوریپو محصول سان اپ برای خدمات آسانسور شرکت بهسان آریان را نگه می‌دارد:

- `admin/` — پنل مدیریت عملیات
- `expert/` — اپ مشترک میدانی؛ امکانات اکسپرت و توسعه امکانات کلاینت با نقش و منوی بک‌اند
- `backend/` — API مبتنی بر Django

تاریخچه‌ی ورودی‌های اولیه با subtree حفظ شده است. اپ مستقل اشتباه کلاینت از اجرای فعال حذف شده؛ منشأ و اقدام در [HANDOFF](HANDOFF.md) ثبت است. امکانات کلاینت در اپ مشترک هنوز کامل نشده‌اند.

برای اجرا [LOCAL_DEV](LOCAL_DEV.md)، برای دامنه و ترتیب توسعه [برنامه جامع](docs/MASTER_PLAN.md) و برای کار انجام‌شده و ادامه کار [HANDOFF](HANDOFF.md) را ببینید. مخزن اصلی `https://git.cloubit.com/saanapp/mono.git` و شاخه توسعه فعلی `test` است. نسخه عمومی در `https://github.com/cloudyhope/saan_cloud.git` با [فرایند همگام‌سازی امن](docs/REPOSITORY_SYNC.md) به‌روز می‌شود؛ تاریخچه قدیمی مخزن اصلی نباید مستقیم به GitHub ارسال شود.
